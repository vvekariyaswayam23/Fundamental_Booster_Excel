# 📊 PR. 1 Fundamental Booster — Excel Project

## 📌 Project Overview
This project completes the **PR. 1 Fundamental Booster** Excel tasks using the supplied Student Grade, Sales Data, and Employee Data.

## 📁 Workbook Structure
- `README` — project overview
- `Students` — grade classification, COUNTIFS, IF/AND, AVERAGEIFS, FILTER and date analysis
- `Sales` — discount calculation, VLOOKUP, XLOOKUP, SUMIFS, AVERAGEIFS, INDEX/MATCH, XMATCH, INDIRECT and OFFSET
- `Employees` — XLOOKUP, joining-date analysis, years of service and salary bands
- `Functions` — reference sheet containing the required Excel functions and examples

## 🧮 Functions Covered
- Relative & Absolute References
- IF / Nested IF
- IF with AND / OR
- COUNTIFS
- SUMIFS
- AVERAGEIFS
- VLOOKUP
- XLOOKUP
- XMATCH
- INDEX + MATCH
- LEFT / FIND / UPPER / LOWER
- INDIRECT
- OFFSET
- Date & Time functions
- FILTER
- ROUND / CEILING / FLOOR

## 🎯 Main Tasks Completed
1. Classify student grades using IF formulas.
2. Count students scoring above 60.
3. Retrieve product prices using lookup functions.
4. Fetch employee salaries dynamically using XLOOKUP.
5. Analyze employee joining dates.
6. Filter students with high scores.
7. Apply formatting and number/date formats.
8. Demonstrate relative and absolute references.
