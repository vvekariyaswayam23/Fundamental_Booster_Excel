## 🚀 About the Project

**Fundamental Booster** is an Excel practice project designed to strengthen fundamental and intermediate spreadsheet skills through real-world-style datasets.

The workbook uses formulas and lookup functions to analyse student performance, calculate sales discounts and net sales, and retrieve employee information.

## 🎯 Project Objectives

- Practise commonly used Excel formulas and functions.
- Perform conditional calculations and multi-criteria analysis.
- Search and retrieve information using lookup functions.
- Work with dates, text, and mathematical functions.
- Organise datasets into clear, structured worksheets.

## 📁 Workbook Structure

| Worksheet | Description |

## ✨ Key Features

### 🎓 Students – Grade Analysis
- Calculates grades using average marks and nested `IF`.
- Checks whether Math marks are greater than 60.
- Checks multiple subject conditions using `AND`.
- Calculates completed years since enrollment using `DATEDIF`.
- Summarises student performance using `COUNTIFS` and `AVERAGEIFS`.
- Filters students whose average score is above 80 using `FILTER`.

### 💰 Sales – Sales Analysis
- Calculates discount percentages based on sales amount.
- Calculates discount amount and net sales.
- Retrieves product prices using `VLOOKUP` and `XLOOKUP`.
- Finds product positions using `XMATCH`.
- Performs conditional totals and averages using `SUMIFS` and `AVERAGEIFS`.
- Demonstrates `INDEX` with `MATCH`.
- Uses `INDIRECT` and `OFFSET` for dynamic cell references.

### 👨‍💼 Employees – Employee Analysis
- Calculates years of service from joining dates.
- Classifies salaries into High, Medium, and Low bands.
- Retrieves employee salary, name, and department using `XLOOKUP`.

## ▶️ How to Use

1. Download or clone this repository.
2. Open `PR1_Fundamental_Booster.xlsx` in Microsoft Excel.
3. Visit each worksheet: Students, Sales, Employees, and Functions.
4. Select formula cells to view and understand the formulas.
5. Change sample input values to practise how the calculations update.

> **Note:** Functions such as `XLOOKUP`, `XMATCH`, and `FILTER` require a compatible Excel version, such as Microsoft 365 or Excel 2021 and later. Dynamic-array results may spill into neighbouring cells.
